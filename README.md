# MailGuard — An Automated Email Safety and Phishing Detection System

A local, explainable phishing-detection tool built as part of a Cyber
Security & Ethical Hacking internship. Paste an email or upload a
`.eml` file and MailGuard returns a risk score, a category (Safe →
Confirmed Phishing), and the specific reasons behind the verdict — all
analysed locally, with nothing sent to any external server.

## 1. Install dependencies

```
cd mailguard
pip install -r requirements.txt
```

## 2. Train the content classifier (one-time step)

```
python model/train_model.py
```

This creates `model/classifier.joblib`. It only needs to be run once
(re-run it if you edit the training data in `model/train_model.py`).

## 3. Run the app

```
python app.py
```

Then open **http://localhost:5000** in your browser.

## 4. Try it out

Two sample emails are included in `sample_emails/`:

- `genuine_newsletter.eml` → should score **Safe**
- `phishing_bank.eml` → should score **High Risk / Confirmed Phishing**

Upload either one on the home page, or paste your own raw email source
into the text box.

## Project structure

```
mailguard/
├── app.py                        Flask entry point
├── requirements.txt
├── mailguard_core/
│   ├── parser.py                 Parsing Layer — headers, body, URLs, attachments
│   ├── header_analysis.py        Sender & Header Legitimacy (25%)
│   ├── url_analysis.py           URL & Link Analysis (25%)
│   ├── content_analysis.py       Content Analysis / NLP (25%)
│   ├── attachment_analysis.py    Attachment Scanning (15%)
│   ├── structural_analysis.py    Structural Anomalies (10%)
│   └── scorer.py                 Combines everything into a final verdict
├── model/
│   ├── train_model.py            Trains & saves the TF-IDF + Naive Bayes classifier
│   └── classifier.joblib         Saved trained model (generated by train_model.py)
├── templates/
│   ├── index.html                Email submission screen
│   └── result.html                Risk verdict screen
├── static/style.css              Navy / cyan theme
└── sample_emails/                 Test emails
```

## Notes & limitations

- The bundled classifier is trained on a small illustrative dataset
  (40 samples) so the prototype works out of the box. For real-world
  accuracy, replace the dataset in `model/train_model.py` with a much
  larger, properly labelled set (as described in the internship
  report) and re-run the training script.
- Attachment scanning is metadata-only (filename/extension checks) —
  no binary or behavioural malware analysis is performed.
- This is a standalone local tool; it is not yet integrated with a
  live mailbox via IMAP/API (see "Future Scope" in the report).
